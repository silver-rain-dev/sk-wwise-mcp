- [2026-10-03, wave 1, issue #2] The canonical Profile table lives in `core/profiles.py`. Import `PROFILES` (name -> server list), `PROFILE_NAMES` (ordered list), `DEFAULT_PROFILE` ("author") and `resolve_profile(name)` (returns a new list; raises `ValueError` listing valid names for an unknown name). `mcp_config(name)` builds the per-server `.mcp.json` content.
  - Why: one source so the exe, legacy profile files, README role tables and later cards cannot drift.
  - Affects: #5 (routing guidance: call `resolve_profile`, or take the mounted server names from `cli`), #6 (manifest `user_config.profile` enum = `PROFILE_NAMES`, default `DEFAULT_PROFILE`).

  - Why: keeps the registry in `cli.py` as other cards expect, with a guard against drift.
  - Affects: #4 and any card that adds or renames a server.
